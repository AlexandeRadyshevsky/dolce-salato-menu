# Фото товаров в максимальном качестве

Источник — оригиналы из папки `Links` InDesign-каталога (Я.Диск), а не сжатые
картинки внутри PDF.

1. `idml_placements.py <idml_dir> placements.json` — все картинки каталога из IDML:
   страница, файл-оригинал, рамка, матрица размещения (поворот/отражение/масштаб).
2. `match2.py menu.json placements.json catalog.pdf <фото_из_pdf> matches.json` —
   точное сопоставление товара с рамкой: воспроизводится рендер области PDF
   (корреляция ≥ 0.99), затем рамка IDML по перекрытию.
3. `hq_photos.py matches.json <links> <фото_из_pdf> <out> report.json` — оригинал
   кадрируется ровно как в каталоге (вкл. повёрнутые рамки), CMYK→sRGB по профилю,
   сверка с PDF, единый стиль (товар по центру квадрата, поля 8%, белый фон),
   маленькие оригиналы увеличиваются нейросетью Real-ESRGAN (realesrgan-x4plus,
   бинарник realesrgan-ncnn-vulkan кладётся рядом в папку `esrgan/`).
   Результат: `<slug>.jpg` 1200×1200 и `<slug>-600.jpg` для карточек.
